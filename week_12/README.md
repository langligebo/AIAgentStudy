# 第 12 周：服务化与运行可靠性

[总目录](../README.md#课程总目录) · [学习计划](../LEARNING_PLAN.md#week-12) · [学习进度](../LEARNING_PROGRESS.md)

任务接口管理长工作，运行控制处理资源与取消，部署回退必须验证持久状态和版本兼容。

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [任务式 FastAPI 接口](session_01/README.md) | 用提交、查询和取消接口管理长任务，区分 HTTP 请求成功与业务任务完成。 |
| 02 | [并发、超时、限流与取消传播](session_02/README.md) | 限制并发和总耗时，仅对可重试读取退避，并在取消后停止启动后续动作。 |
| 03 | [部署准备、健康检查与回退](session_03/README.md) | 区分存活与就绪，检查版本和状态恢复条件，并为失败版本回退提供可执行步骤。 |
| 04 | [持久任务队列、租约与事务发件箱](session_04/README.md) | 理解进程崩溃和重复投递时如何接续任务，不丢状态也不重复业务写入。 |
| 05 | [事件流、背压与人工审核体验](session_05/README.md) | 使客户端断线和慢消费时仍能理解任务状态，审批精确绑定动作。 |
| 06 | [性能、路由、缓存与服务降级](session_06/README.md) | 在相同质量约束下测成本与延迟，不通过放宽授权换取速度。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
