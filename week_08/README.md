# 第 08 周：LangGraph、持久化与人工介入

[总目录](../README.md#课程总目录) · [学习计划](../LEARNING_PLAN.md#week-08) · [学习进度](../LEARNING_PROGRESS.md)

图负责编排，checkpoint 负责保存执行位置，业务幂等负责避免重复副作用；三种保证不能混淆。

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [LangGraph 的 State、Node 与 Edge](session_01/README.md) | 将已理解的循环映射到图状态、节点更新和条件边，并用相同输入比较行为。 |
| 02 | [Checkpoint、人工审批与恢复](session_02/README.md) | 在具体写入动作前保存状态，理解重启恢复、批准、修改与拒绝的差别。 |
| 03 | [重放、副作用与结果未知](session_03/README.md) | 在返回丢失后核对真实业务状态，用持久幂等避免恢复导致重复工单。 |
| 04 | [LangGraph 并行状态、子图与流式事件](session_04/README.md) | 理解 reducer、并行合并、子图边界和事件输出，防止迁移后丢状态。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
