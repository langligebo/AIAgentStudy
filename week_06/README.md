## 使用方式

按 Session 顺序学习，原基线每节约 2 小时；补充策略对照按实际掌握分次实践，第三节同时复盘。压缩、Agentic RAG 与 RAGAS 分别接第 7、9、10 周，不要求本周一次完成全部技术。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
