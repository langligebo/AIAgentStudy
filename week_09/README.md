## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [固定工作流、路由与并行依赖](session_01/README.md) | 为明确业务流程选择串行、条件路由或独立并行，并用事件证明依赖顺序。 |
| 02 | [动态计划、重新规划与 Skill 复用](session_02/README.md) | 校验模型提出的计划，在观察或目标变化后废止过期步骤，并限制重新规划成本。 |

| 04 | [多 Agent 分工、交接与协作评估](session_04/README.md) | 能选择单 Agent、主管分工或交接模式，并把总预算、证据和责任传下去。 |
| 05 | [A2A 与跨 Agent 任务协议](session_05/README.md) | 区分本进程分工与跨服务协作，识别发现、任务状态、产物及授权边界。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
