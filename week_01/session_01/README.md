# Session 01：Temperature 对比实验

使用项目配置中的模型（当前默认 `qwen2.5:14b`）对同一个 prompt 分别设置 `temperature = 0 / 0.5 / 1.0`，每组运行 3 次，共 9 次独立请求。
脚本只使用 Python 标准库，无需安装额外 Python 依赖。

## 运行

地址、模型和超时从项目根目录的 [config.toml](../../config.toml) 读取。当前配置为 `http://192.168.31.98:11434`、`qwen2.5:14b`、300 秒。请确保服务器上的 Ollama 已启动且该地址可访问；根据你提供的列表，服务器已有 14b 和 3b 模型。

在项目根目录运行：

```bash
uv run python week_01/session_01/main.py
```

也可以直接使用本机 Python：

```bash
python3 week_01/session_01/main.py
```

自定义 prompt（整轮实验的 9 次请求仍使用相同内容）：

```bash
uv run python week_01/session_01/main.py --prompt "请提出三个有创意的 AI 学习项目，每个用一句话介绍。"
```

可选参数：`--model`、`--host`、`--prompt`、`--timeout`。
其中 `--model`、`--host`、`--timeout` 优先于配置文件，只覆盖本次运行；不传时全部使用统一配置。首次加载模型较慢时，可以添加 `--timeout 600`。

例如，临时使用服务器上的 3b 模型：

```bash
uv run python week_01/session_01/main.py --model qwen2.5:3b
```

模型调用已抽到 [common/llm.py](../../common/llm.py)：本脚本通过 `create_llm_client()` 创建客户端，再调用 `client.generate()`。后续 Session 复用同一入口，详见[项目配置说明](../../README.md#统一配置)。HTTP 请求、Ollama 参数转换与响应解析都在公共模块中处理。

## 实验设计

- 使用有多种合理回答的创意 prompt，方便观察表达差异。
- 三组均使用 `seed = 42、43、44`，每组内种子不同，各组同一次数的种子相同，便于配对比较。种子可以帮助复现实验；每组连续复用同一个固定种子会抑制想观察的随机差异。
- 固定 `top_p = 0.9`、`top_k = 40`、`max_tokens = 512`；更改参数可以编辑脚本顶部的 `FIXED_OPTIONS`。公共调用模块会将 `max_tokens` 转为 Ollama 的 `num_predict`，实际请求参数保持不变。
- 每次请求独立，不携带上一轮回答或上下文；串行运行，不自动重试。
- `stream = false`，通过 Ollama 的 `/api/generate` 接口读取完整响应。

接口和参数依据：[生成接口](https://docs.ollama.com/api/generate)、[参数说明](https://docs.ollama.com/modelfile#valid-parameters-and-values)。

## 查看结果

所有结果只打印到控制台，不创建结果目录、JSON 文件或 Markdown 报告：

- 开始时打印服务地址、模型、超时、prompt、种子和固定参数。
- 每次调用后打印原始回答、耗时、结束原因和输出 token 数。
- 结束时打印已完成次数，以及三种温度的统计对照表。

遇到错误或手动中断时，控制台仍会汇总已完成的回答，并以非零退出码结束；不足两次的组不计算字符相似度。运行中的回答只保存在进程内存里。有价值的观察可以自行整理进学习笔记。

## 如何观察

1. **不同输出数**：一组只有 1 种输出，说明三次文本一致；有 3 种输出，说明三次各不相同。
2. **完全相同的配对**：每组有三对比较（1–2、1–3、2–3），`3/3` 表示三次输出都一致。
3. **平均字符相似度**：越接近 100%，文字越接近。这是字符层面的指标，不表示语义一致或回答质量。
4. **人工阅读**：比较名字、观点、措辞、格式约束的遵守情况；高温下多样性增加不等于质量更高。
5. **截断情况**：若结束原因为 `length`，提高 `FIXED_OPTIONS` 中的 `max_tokens` 后重新运行完整实验，避免用截断回答作比较。

统计时只忽略回答首尾空白，控制台打印返回的原始文本。
预期低温输出更稳定，高温更容易出现差异；这只是待观察的趋势，脚本不会预先判定结果。
温度为 0 也不应被理解为在所有版本、硬件和运行条件下都保证逐字一致；每组 3 次属于小样本观察。
