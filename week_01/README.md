## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

保留[第一周原始笔记](week1-llm-agent-basics.md)。真实温度与 Prompt 实验使用现有脚本；结果只打印控制台。第一周 Prompt 实验已有用户运行证据，其他验收以进度记录为准。
