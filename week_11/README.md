# 第 11 周：MCP 与安全边界

[总目录](../README.md#课程总目录) · [学习计划](../LEARNING_PLAN.md#week-11) · [学习进度](../LEARNING_PROGRESS.md)

MCP 统一接入，适配层连接模型协议与工具，安全边界仍在身份、授权、执行器和数据过滤中。

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [MCP 架构、发现与调用协议](session_01/README.md) | 区分 Host、Client、Server，追踪初始化、工具发现、调用和错误层次。 |
| 02 | [Python MCP 服务与客户端适配](session_02/README.md) | 把订单查询封装为 MCP 工具，将发现的元数据转换为模型工具说明，并保留可信身份和错误状态。 |
| 03 | [提示注入、最小权限与安全回归](session_03/README.md) | 用本地虚构攻击文本验证工具授权、数据隔离、写入审批和日志边界。 |
| 04 | [远程 MCP、能力协商与授权](session_04/README.md) | 把本地 stdio 实验扩展到远程信任边界，理解认证、授权和版本兼容的不同职责。 |
| 05 | [执行隔离、浏览器动作与威胁建模](session_05/README.md) | 给文件、代码、浏览器和网络工具建立可测试的边界，明确沙箱保护的范围。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
