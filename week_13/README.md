# 第 13 周：综合项目与验收

[总目录](../README.md#课程总目录) · [学习计划](../LEARNING_PLAN.md#week-13) · [学习进度](../LEARNING_PROGRESS.md)

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [综合项目需求与验收设计](session_01/README.md) | 把“知识库客服助手”定义成可验证的任务边界和场景矩阵，先写成功与禁止条件。 |
| 02 | [端到端整合与故障修复](session_02/README.md) | 沿用户目标串联 Skill、检索、记忆、审批和工具，以一组故障定位集成边界。 |
| 03 | [基础项目验收、演示与学习复盘](session_03/README.md) | 以预定标准验收最终系统，对照基线交付可复现说明和明确限制。 |
| 04 | [综合工程分层与端到端契约测试](session_04/README.md) | 把各节机制连成同一个可替换、可诊断的系统，验收真实边界而非函数数量。 |
| 05 | [CI、发布、备份恢复与生产验收](session_05/README.md) | 使他人能重建环境、部署、回退和恢复，并用事先标准决定能否交付。 |
| 06 | [模型适配、训练路线与课程总复盘](session_06/README.md) | 能判断何时使用 Prompt、RAG、工具、Skill 或训练，并把后续专项学习建立在现有证据上。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
