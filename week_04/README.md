# 第 04 周：手写 Agent 循环与任务状态

[总目录](../README.md#课程总目录) · [学习计划](../LEARNING_PLAN.md#week-04) · [学习进度](../LEARNING_PROGRESS.md)

预算约束循环，任务状态表达目标和更正，环境反馈支撑终态。用户取消和模型说完成都需要程序核对。

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [最小 Agent 执行循环](session_01/README.md) | 手写决策、执行、观察、再次决策的循环，并用步数和工具预算限制运行。 |
| 02 | [任务状态、追问、更正与取消](session_02/README.md) | 把任务事实与聊天记录分开，建立有版本的任务状态，并阻止旧动作在用户更正后执行。 |
| 03 | [环境反馈、完成验证与退出](session_03/README.md) | 在工单创建后核验实际状态，识别假完成、无进展和不可解释的退出。 |
| 04 | [把真实模型接入手写循环](session_04/README.md) | 在同一个循环里替换决策器，保留工具权限、预算、观察和完成依据。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
