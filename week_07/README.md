# 第 07 周：上下文编排与记忆

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [上下文选择与预算](session_01/README.md) | 在有限预算内保留目标、约束和必要证据，并解释裁剪策略的损失。 |

| 04 | [记忆写入、检索与巩固评估](session_04/README.md) | 把长期记忆做成有来源、有用途、可纠正的闭环，而不是无限保存聊天。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
