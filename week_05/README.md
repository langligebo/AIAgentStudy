## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [编写售后处理 Skill](session_01/README.md) | 编写描述适用范围、步骤和失败分支的 Skill，并区分说明文件、辅助资料和执行工具。 |
| 02 | [Skill 发现、选择与渐进加载](session_02/README.md) | 先提供元数据供选择，再读取被选 Skill 正文和必要资料，记录加载过程。 |
| 03 | [Skill 评估、版本与回退](session_03/README.md) | 用相同案例比较无 Skill、旧版和新版，发现误触发、漏触发及流程退化。 |
| 04 | [Skill 包验证、依赖与宿主生命周期](session_04/README.md) | 把可加载的文档包变成可审查、可回退的运行时资源，区分 Skill、插件、钩子和权限。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
