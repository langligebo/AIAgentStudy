## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [分层评估与评分器校准](session_01/README.md) | 分别定位格式、检索、工具选择、轨迹和业务终态错误，并认识模型评分的边界。 |
| 02 | [结构化追踪与实验复现](session_02/README.md) | 用任务和步骤标识串联请求、观察和状态，记录版本并避免在日志中泄露凭据。 |
| 03 | [配对对照、回归与发布判断](session_03/README.md) | 用固定开发集、保留集和重复运行分析改进与退化，结合质量、调用量和成本判断。 |
| 04 | [数据集设计、统计不确定性与评分器偏差](session_04/README.md) | 避免用少量挑选样本宣布改进，能设计可重复、分层且不泄漏的评价。 |
| 05 | [追踪接入、线上反馈与 RAGAS 适配](session_05/README.md) | 把本地事件映射成可关联的观测数据，并将评分工具接到同一个模型边界。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
