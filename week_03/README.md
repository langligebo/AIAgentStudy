# 第 03 周：工具调用与数据契约

[总目录](../README.md#课程总目录) · [学习计划](../LEARNING_PLAN.md#week-03) · [学习进度](../LEARNING_PROGRESS.md)

工具协议说明如何表达请求，执行器决定能否执行，错误与选择评估解释失败发生在哪一层。

## 本模块课时安排

| Session | 教案 | 目标与练习 |
| --- | --- | --- |
| 01 | [工具调用协议](session_01/README.md) | 能把工具声明、模型提出的调用和程序返回的观察关联起来，处理一轮中的多个调用。 |
| 02 | [工具执行器：契约、业务与权限](session_02/README.md) | 实现一个只允许已注册操作的执行器，并在创建模拟工单前完成参数、订单归属和审批核对。 |
| 03 | [工具错误、选择与重试边界](session_03/README.md) | 把协议错误、业务无结果、部分成功分开，并按动作风险决定能否重试。 |
| 04 | [工具界面设计、检索选择与并发契约](session_04/README.md) | 把工具目录设计成模型能选择、执行器能约束、并发时能关联结果的接口。 |

## 使用方式

按 Session 顺序学习，每节约 2～4 小时；第三节为阶段复盘，最后一节为模块复盘。所有教案已准备，材料存在不表示完成学习。先运行文内最小样例，再改一个正常条件和一个失败条件，最后解释观察与验收标准。

原前三节及新增课的标准库最小示例均有离线验证记录。实际模型、框架联调、持久服务与部署练习是否执行，分别见教案的验证边界与进度记录。独立实验脚本留给学习实践，不在本次批量创建。
